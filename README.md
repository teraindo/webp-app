# 트윗 영상 · WebP 변환기

트윗(X) 영상 다운로드와, 동영상의 원하는 구간을 움직이는 WebP로 바꿔 주는 웹앱입니다.
모든 변환은 휴대폰 안에서 처리되며 영상이 서버로 전송되지 않습니다.

안드로이드 크롬에서 열고 **⋮ → 앱 설치**를 누르면 앱처럼 설치됩니다.

## 사진 이름 바꾸기 (안드로이드 앱)

`android-renamer/` 폴더는 폰 폴더 안 사진의 파일 이름을 직접 바꿔 주는 안드로이드 앱입니다.

- UUID 형식(`E621B27A-3C4D-4F5E-9A8B-1C2D3E4F5A6B.jpg`) 또는 `IMG_0001.jpg` 형식
- 실행 전 미리보기, 마지막 작업 되돌리기
- 설치 파일: [Releases → image-renamer](../../releases/tag/image-renamer) 의 `image-renamer.apk`
